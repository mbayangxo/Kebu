Implemented the part of that choice that is concretely applicable to what already exists: durable retry for digital-product fulfillment, riding the existing (not duplicated) `platform_jobs` worker.

- `lib/shop/digital-downloads.ts` — split into `fulfillPaidDigitalOrder` (raw core; now throws on a genuine failure instead of the original code's silent swallow-and-drop) and `fulfillPaidDigitalOrderDurable` (webhook-facing: tries the core, and on failure enqueues a `digital.fulfill` platform job instead of throwing, so a delivery hiccup never turns an already-successful payment webhook into a 500).
- `lib/platform/worker.ts` — `executeJob` now handles `digital.fulfill` by calling the **raw** core directly, so a real failure flows into the existing `failPlatformJob` attempt-count/backoff/dead-letter path rather than being swallowed.

Fixed by cleanly separating the throwing core (used by the worker) from the non-throwing wrapper (used by webhooks) before any test ran.

### Digital-fulfillment boundary audit — October 16, 2026 UTC

1. **Room creation itself has always been broken for every user.** `app/api/rooms/route.ts`'s POST handler creates a room with `.insert({...}).select("*").single()` (`INSERT ... RETURNING`). 2. **Every write to `room_members` has always failed with "infinite recursion detected in policy for relation room_members"** — including the room creator's own first owner-membership insert during room creation (that specific call had no `.select()`, so the failure was silently swallowed with *zero* error check in the app code) and the "member" action adding any second person to a room (which does check the error, and would 500 every time it was tried). Both bugs stayed completely invisible because `can_access_room()`'s `created_by = auth.uid()` branch already gives a room's own creator full access without ever needing a `room_members` row to exist — a solo room looked entirely functional end to end while no `room_members` row was ever actually created for anyone, and no second person could ever be added to any room.
