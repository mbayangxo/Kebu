# ADR: Studio Create north star (idea → connected creative system)

**Date:** 2026-09-08  
**Status:** Accepted  
**Full text:** `docs/product/KEBU-STUDIO-CREATE-NORTH-STAR.md`

## Decision

Kebu competes with the **stack around** a small business/creator (design + video + brand + sell), not with Canva template count.

1. **AI Creative Director** — start from business/idea; campaign stays connected when direction changes.  
2. **One project → everything** (brand · music · video · marketing · commerce · events).  
3. **African formats & typography** — natural language, modern design language.  
4. **Preserve-creator AI** (esp. product photography).  
5. **Brand DNA** shared across Studio · Builder · Shop · Reach.  
6. **Design → Sell** + offline-first + Rooms + marketplace + cultural intelligence — phased.  
7. **CREATE** = eventual umbrella entry; **Studio** = current creative surface until CREATE orchestration is a real slice.  
8. Video = Visual + Music Intelligence — **not a DAW**.

Implement **one vertical slice at a time**. This ADR does not authorize building all 16 pillars now.
