# ADR: Studio fonts · brand aesthetic apply · posters/banners/cards

**Date:** 2026-09-08  
**Status:** Accepted

## Decision

One vertical Studio Design slice:

1. **Fonts catalog** (`lib/studio/fonts-catalog.ts` + `GET /api/studio/fonts`) — curated families with Google/system stacks; editor + brand kit pick from catalog.  
2. **Brand aesthetic apply** — apply saved brand kit **or** named site aesthetic (`SITE_AESTHETICS`) onto the **open canvas** (Look tab). Builder apply-to-project remains.  
3. **Posters / banners / cards** — `banner` + `business_card` design types, create presets, templates.

## Later (not this slice)

Folders · version history · elements pack · comments/live cursors · CapCut-class video · Brand DNA depth.
