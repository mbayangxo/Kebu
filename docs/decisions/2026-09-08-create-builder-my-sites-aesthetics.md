# ADR: Create · Builder · My Sites · Aesthetics (naming)

**Date:** 2026-09-08  
**Status:** Accepted (updated same day)

## Confusion

People hear **Create** and **Builder** as two products. They are not — and we stop using those labels in chrome.

## Decision (product labels)

| Name in UI | What it is | Primary routes |
|------------|------------|----------------|
| **Aesthetics** | Theme / look **store** (compact gallery → demo → try) | `/create/aesthetics` |
| **Build a site** | Start a new website (under Aesthetic store) | `/create/new` |
| **My Sites** | **Your** website projects only | `/my-sites` |
| **My Space / My KEBU** | Dashboard for your businesses & sites | `/business` |
| **Kebu Studio** | Graphics + video creative tool | `/studio` |
| **Alkebulan** | B2B trade — **not** under My KEBU | `/b2b` |
| **My Account** | Avatar **top-right** only — list of settings | `/account` |

**Mae / owner portfolio sites** (May Lecor cutout+city+logo) stay **out of** the Aesthetic store. Live preview from code: `/create/demo/musician-maylecor-ksendr`.

Register a business stays on Opportunity / signup — not My KEBU nav.

Yande FAB is **draggable** so it does not block account / nav.
