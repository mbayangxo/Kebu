# 3E motion engine — design freeze

2026-10-08 UTC. Authorized continuation toward internal use. The existing canonical node.motion/node.interaction fields gain strict version-1 native payloads. Do not store motion in props or introduce another document model. New setMotion/setInteraction operations use the existing version checks, atomic journal, acknowledgment, conflict/pending draft handling and history; null removes a payload. Copy/reload/publishing preserve the payload.

Native section/group/text/image motion offers Fade, Rise, Slide left/right and Zoom, with page-load or entering-view triggers, bounded duration/delay/distance and named easing. Optional tablet/phone enabled overrides inherit desktop. Interactions offer Lift, Grow and Dim on pointer hover and keyboard focus within an existing link, with bounded duration. These effects do not manufacture navigation or other business actions. Unknown versions, fields, arbitrary script/CSS, invalid values and unsupported payloads reject visibly. No custom timeline authoring is implied by this preset-engine phase.

Use one browser-native animation engine shared by runtime and editor replay. Apply motion on a separate content wrapper so authored spatial transforms remain intact. Editing canvases stay still until explicit replay. Runtime starts from fully visible SSR content, arms entering-view motion only after hydration and cancels observers/animations on changes/unmount. JavaScript disabled, reduced-motion preference and absent animation/observer support retain readable content. Reduced-motion changes cancel immediately and interactions respect coarse pointers, keyboard focus and the preference. Effects return to authored resting state; never leave saved content invisible.

Controls live in a labelled Motion accordion in the existing inspector. Save selection/timing changes normally; replay is transient and never saves. Existing disabled/locked guards apply. Device override reset preserves the other device. Public/published payloads require renderer 7; older snapshot requirements remain readable. CLI-created forward SQL adds protocol cases and supported publisher version without changing owner/RLS/service-only publishing grants. No live migration, default switch, push/merge or deployment.

Acceptance: strict core/API/SQL validation, atomic save/replay/conflict/reload/copy and inverse history; editor controls and unsaved replay; load/enter/hover/focus playback; reduced-motion at startup and dynamically; disabled-device inheritance; JS-off readable output; unchanged authored transforms; detached immutable publication; unknown-payload preservation/errors. Run full local regression/performance and Node 20 CI, inspect visuals and retain evidence. Signed-in QA remains deferred and is not a claimed pass.
