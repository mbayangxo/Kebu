# 3D spatial composition — first implementation slice

User authorized continued development with authenticated QA deferred. Existing 3C/S6/S7 source and release gates are preserved. No production migration, merge, push or deployment is part of this work.

Implement direct move/resize and layer depth for native groups, text and images inside native containers. Desktop is base; tablet and phone use independent sparse overrides. Geometry uses bounded numeric pixels in the parent's content coordinate system; no arbitrary CSS or scripts. The first free-position gesture initializes an unset parent canvas height to 600px in the same transaction. Container minimum height is explicit, preventing absolute children from collapsing their canvas. Flow remains the default and old documents render unchanged.

Reuse the canonical node props, strict schemas, operation endpoint, optimistic versions, existing history and publish envelope. Spatial snapshots require renderer 3; older native snapshots still accept renderer 2. A forward migration extends the service-only publisher’s supported renderer versions while preserving its locking, hash verification and grants. Commit one transaction on pointer release; cancelled gestures commit nothing. A rejected save retains the existing coordinator’s pending draft, clearly labels the failure, preserves confirmed server geometry and blocks publishing; it never silently retries or reports success. Drag ghosts are isolated from React-owned geometry so an incoming canonical edit cannot be overwritten during cancellation. Keyboard/numeric position and size controls provide a pointer-independent alternative. Locks prevent editor manipulation of a locked node or its descendants; locks are an editing guard, not an authorization boundary. Owner/RLS enforcement remains unchanged.

Use the existing inspector with a spatial section, existing selection outline, compact move/resize controls and a layer-depth field. No new app navigation. Preview and public runtime share the renderer, including pre-hydration responsive geometry. Device iframe edits post bounded geometry to the parent, which validates identity, source/origin and creates operations through the same write boundary.

Acceptance: drag, resize, lock/unlock, independent device geometry, layer overlap, Undo/Redo, reload, detached publishing, cancellation, invalid-number rejection and legacy compatibility. Run unit/transaction/renderer checks, actual browser gestures and full CI. Signed-in remote QA stays pending and does not become a claimed pass.

This is the first 3D slice. Full 3D also requires alignment/snapping/guides, extended constraints/transforms and richer responsive art direction before its final gate; those requirements remain recorded rather than silently removed.
