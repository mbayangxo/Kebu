## Status meaning

- **Development implemented/tested**: source plus recorded development evidence. Does not mean live/released.
- **Partial**: some implementation exists; listed scope or verification is incomplete.
- **Not started/not established**: explicit product status says not started, or no full product was established by inspected evidence. Absence of a route alone is not proof no code exists anywhere.
- **Mismatch/conflict**: implementation or sources disagree with recovered requests; reconcile before changing behavior.
- **Live unverified**: the exact user-facing flow was not tested in an authenticated production session.
