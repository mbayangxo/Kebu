# Reference dossier format (product benchmarks)

**Do not give Cursor only a product name.** Names are insufficient — agents do not hold accurate models of current Canva, Shopify, or Spotify.

For every major reference product, create a **reference dossier**: systems, workflows, quality bar, and annotated visuals.

**Folder:** `docs/reference/{product}/PRODUCT-BENCHMARK.md` + screenshots in same folder.  
**Builder law:** `docs/product/KEBU-BUILDER-NEXT-GEN.md` · **Templates:** `docs/product/KEBU-TEMPLATE-INTELLIGENCE.md`

---

## Dossier structure (copy per product)

```markdown
# {PRODUCT} — Product benchmark (NOT a clone target)

## What it is (one line)
## Systems to study (bulleted — complete workflow, not one screen)
## What NOT to copy
## Visual references (files in this folder)
## Design principles to extract (not surface resemblance)
## Kebu translation (what we build differently)
```

---

## Rules for all dossiers

1. **Never optimize for surface resemblance.** Optimize for understanding the **underlying product system**.  
2. **Never substitute a simplified UI for a complete workflow.**  
3. **Extract principles from references** — do not pixel-copy competitor chrome.  
4. Add **5–10 visual references** per aesthetic when quality bar matters (luxury fashion, beauty editor, etc.).  
5. Annotate: **GOOD** · **BAD** · **IMPORTANT**

## Ultimate Cursor quality rule (all Kebu projects)

> Never optimize for resemblance at the surface level. Optimize for understanding the underlying product system.  
> Never substitute a simplified UI for a complete workflow.  
> Never generate generic templates merely to satisfy a template count.  
> Every design must have intentional purpose, audience, hierarchy, interaction model, and visual identity.  
> **If the result looks like an AI-generated approximation, it has failed quality review and must be redesigned.**

Applies to: Kebu Builder · Kebu Studio · Property platform · any assigned slice.

---

## One template at a time

Do **not** generate 30 templates at once.

1. Create **ONE exceptional** template / design world.  
2. Run **design-quality review** (see `KEBU-DESIGN-QUALITY-STANDARD.md`).  
3. Only after pass — extract principles → next **distinct** archetype.

Quality → 1 amazing template beats quantity → 20 generic templates.
