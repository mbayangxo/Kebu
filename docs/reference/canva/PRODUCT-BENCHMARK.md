## Editor requirements (maturity bar)

Treat the editor as a **professional creative application**:

- Persistent application shell · contextual toolbars  
- Canvas manipulation · layers · pages  
- Typography controls · image/media management  
- Undo/redo · keyboard shortcuts · zoom/pan  
- Selection · resize · align · group · duplicate · copy/paste  
- Templates · uploads · project persistence · autosave · export  
- AI-assisted creation (on top of real project model — not textarea → shape)
