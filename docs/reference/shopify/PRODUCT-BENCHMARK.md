# Shopify — Product benchmark (NOT a clone target)

**Use with:** annotated screenshots in this folder · `docs/product/KEBU-TEMPLATE-INTELLIGENCE.md`

---

## What it is

Shopify is a **commerce operating system**, not merely an online store builder.

Study it as a **collection of systems** — not one theme editor screen.

---

## Systems to study

- Merchant dashboard · product management · inventory · orders · customers  
- Analytics · payments · discounts · marketing · shipping · settings  
- **Storefront** · **theme/template system** · visual site editor  
- Navigation editor · page builder · checkout  
- Apps / integrations · theme marketplace  

---

## Theme system (critical — not “single page editor”)

```
Theme
  → templates (home, product, collection, cart, …)
  → sections
  → blocks
  → settings (typography, colors, spacing)
  → responsive behavior
  → navigation
  → product / collection templates
  → cart · checkout · pages · blog/content
```

**Kebu translation:** Structured `website-v1` schema + design tokens + section types — **not** Liquid clone, **not** one static HTML page.

---

## Theme marketplace lesson

Do **not** give users 20 copies of the same website.

**Categories** (each with **multiple genuinely different art directions**):

Luxury Fashion · Streetwear · Beauty · African Fashion · Jewelry · Restaurant · Café · Bakery · Furniture · Electronics · Home Goods · Art · Creator · Services · …

Same category ≠ same layout with different colors.

---

## What NOT to copy

- Shopify admin chrome as Kebu Business OS wholesale  
- Generic “Hero + three cards + button” as a “theme”  
- Surface-level green/black branding pass  
- Assuming Shopify editor UX from the name alone without screenshots
