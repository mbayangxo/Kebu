# Kebu Palaver pilot

The /palaver route is off unless KEBU_PALAVER_PILOT_SITE names a dedicated, published, unsuspended, non-password-protected community site. Use a new QA project, not an existing merchant or fan community; the page and site board share their data and project-owner moderation.

The pilot uses the existing signed-in posts, replies and thread moderation. It is a text-first community surface. No trending feed, private messaging, follows, blocking or report queue is introduced here. Before wider access, verify owner and member accounts in a protected QA preview and add in-product reporting and blocking. City and country trends should start as moderated topics with sources; automate only after there is enough genuine participation to measure trends meaningfully.

Checkout remains a separate release track: the current checkout branch has Git deployments disabled. A protected preview must point exclusively to Kebu-qa, with isolated signing and sandbox provider settings, before purchase and provider-refund acceptance. Do not treat a Vercel account unblock as a deployed preview.
